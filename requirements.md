# Projects Requirements

## Patients - Requirements

1. Patients Registration - Required Fields:
   - Email
   - Username
   - Password
   - Confirm password
   - Full Name
   - Date of Birth
   - Phone Number
   - Address
   - Blood Group
2. Log In - Required Fields for Log In:
   - Username or Email
   - Password
   - 2 Factor Authorization
3. View and Sort
4. Book Appointments.
5. Cancel Appointments.
6. View Appointments History.

## Doctor - Requirements

1. Doctors Registration - Required Fields:
   - Email
   - Username
   - Password
   - Confirm password
   - Real Name
   - Date of Birth
   - Phone Number
   - Address
   - Qualifications
2. View Own Appointments
3. Approve/Reject Appointments
4. Update Appointment with Approval of Patients
5. Mark Appointments Complete

## Admin - Requirements

1. Manage Doctors
2. Manage Patients
3. View/Update Appointments
